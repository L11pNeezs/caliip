# 003: PWA with vite-plugin-pwa

**Status:** Accepted; manifest and production service worker configured.

## Context

Caliip is a PWA. Application assets should support offline loading, and future
locally stored meals should remain viewable without external API access.

## Decision

Use vite-plugin-pwa to generate the web app manifest and service worker as part
of the Vite build. This keeps PWA configuration alongside the existing frontend
tooling rather than adding a separate build system.

The current scaffold uses automatic service worker updates, precaches built
application assets, and excludes `/api` paths from navigation fallback. It does
not cache API responses. The service worker is generated for production builds
and is not registered in development.

## Consequences

- Production builds include the manifest and service worker for PWA support.
- Offline meal access will depend on implementing the documented local database
  and views; the scaffold does not yet offer meal tracking.
- OpenAI and USDA calls still need an internet connection.
- Production hosting must provide the SPA fallback and route `/api/*` to Bun.
